# Yovel ContentFlow · Documentación pública

Página estática de privacidad y condiciones para una herramienta personal de
productividad editorial de Yovel Quino. Alojamiento: GitHub Pages.

Este repositorio contiene únicamente documentación pública. La publicación de
esta página no constituye aprobación de LinkedIn ni activa el flujo cloud.
La URL de producción debe verificarse antes de usarla en el registro de la app.

No requiere servidor propio, dependencias, JavaScript ni generación de IA.
